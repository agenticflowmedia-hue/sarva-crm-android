OM SARVA BHUTA CRM Android APK source project
This is an Android Studio project, NOT a compiled APK.
Requires Android Studio with Android SDK 35 and JDK 17.
Open this folder in Android Studio; allow Gradle sync.
Build > Build Bundle(s) / APK(s) > Build APK(s).
Result: app/build/outputs/apk/debug/app-debug.apk.
The app is an online WebView wrapper of https://om-sarva-bhuta-crm-secure.vercel.app/.
Internet is required. Test login, navigation, and enrollment on a device before distribution.
Use a signed release APK for external distribution; debug APK is for testing.
